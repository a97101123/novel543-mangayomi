# Novel543 for Mangayomi

Mangayomi JavaScript novel extension, version 0.3.0, based on the user-tested extension.

## Publish

1. Create a PUBLIC GitHub repository named `novel543-mangayomi`.
2. Replace `YOUR_USERNAME` with your actual GitHub username in `novel_index.json`.
3. Upload `novel_index.json` and `novel543.js` to the repository root of `main`.
4. Add this repository URL to Mangayomi's NOVEL repository list:

   `https://raw.githubusercontent.com/YOUR_USERNAME/novel543-mangayomi/main/novel_index.json`

## Update

Keep the same ID (`54303026`) and increase the `version` in BOTH `novel_index.json` and `novel543.js`; replace the script, commit, and refresh the repository in Mangayomi.

## Notes

This bundle is not yet published or independently tested on iOS. Cloudflare challenges may still occur. The original in-app locally created source may remain separately installed: make a backup before migration, because library/history continuity is not guaranteed.

This extension is an independent, unofficial integration. It does not include book text or other content from the source site.
